# Prompt: Planmodus

```text
Arbeite im Planmodus und ändere noch keinen Code.

Aufgabe:
[Aufgabe]

Erstelle:
- eine Wiedergabe der Aufgabe in eigenen Worten,
- Ist-Zustand und Soll-Zustand,
- Scope und Nicht-Scope,
- betroffene Bereiche und Dateien in sinnvoller Untersuchungsreihenfolge,
- Risiken, Annahmen und offene Punkte,
- eine kleine geordnete Todo-Liste,
- beobachtbare Akzeptanzkriterien,
- eine Test- oder Verifikationsstrategie.

Teile die Aufgabe auf, falls sie mehrere unabhängige Ziele oder einen zu großen Diff erzeugen würde.
```
