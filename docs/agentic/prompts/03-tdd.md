# Prompt: TDD

```text
Arbeite testgetrieben nach Red → Green → Refactor.

Gewünschtes Verhalten:
[Verhalten aus Nutzersicht]

1. Formuliere Hauptfall, Fehlerfall und einen Randfall.
2. Schreibe zuerst den kleinsten geeigneten Test.
3. Führe ihn aus und bestätige, dass er aus dem erwarteten Grund fehlschlägt.
4. Implementiere nur genug Produktivcode, um den Test grün zu machen.
5. Führe fokussierte und verwandte Tests aus.
6. Refaktoriere nur bei grünen Tests und nur falls nötig.
7. Schwäche oder überspringe keine Tests.

Berichte Red-, Green- und gegebenenfalls Refactor-Schritt getrennt.
```
